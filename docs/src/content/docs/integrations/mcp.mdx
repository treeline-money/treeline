---
title: MCP Server
description: Use Treeline from Claude Desktop, ChatGPT, and other AI agents.
---

Treeline includes a built-in [MCP](https://modelcontextprotocol.io/) (Model Context Protocol) server. This lets AI agents query your finances, sync accounts, tag transactions, and more — directly from tools like Claude Desktop and ChatGPT Desktop.

Your data stays local. The MCP server runs on your machine and reads from your local Treeline database.

## Setup

### Claude Desktop

Open **Settings > Developer > Edit Config** and add:

```json
{
  "mcpServers": {
    "treeline": {
      "command": "tl",
      "args": ["mcp"]
    }
  }
}
```

Restart Claude Desktop. You should see Treeline listed in the tools menu.

### ChatGPT

ChatGPT supports MCP via [remote HTTP servers](https://developers.openai.com/api/docs/mcp/) only — it does not support local STDIO servers directly. To use Treeline with ChatGPT, you would need to host the MCP server behind an HTTP endpoint, which conflicts with Treeline's local-first design. This may be supported in the future.

### Other MCP clients

Claude Code, Gemini CLI, Cursor, and any other client that supports the MCP STDIO transport can connect. Point it at `tl mcp` as the command.

For example, in Claude Code:

```bash
claude mcp add treeline tl mcp
```

## Available Tools

Once connected, the agent has access to these tools:

| Tool | Description |
|------|-------------|
| `status` | Account balances, transaction counts, and connected integrations |
| `query` | Execute a read-only SQL query against your financial database |
| `query_write` | Execute a SQL query with write access (INSERT, UPDATE, DELETE) |
| `sync` | Pull latest transactions from connected bank integrations |
| `tag` | Apply tags to transactions |
| `doctor` | Run database health checks |
| `demo` | Enable, disable, or check demo mode |

## Usage

You don't need to mention Treeline or MCP by name. Just ask questions naturally:

- "What's my net worth?"
- "How much did I spend on groceries last month?"
- "Show me my largest transactions this week"
- "Tag all Starbucks transactions as coffee"
- "Sync my bank accounts"

The agent will choose the appropriate Treeline tool based on your question.

## Privacy

The MCP server runs locally and reads directly from your Treeline database on disk. No financial data is sent to any server by the MCP server itself.

However, the AI agent you're using (Claude, ChatGPT, etc.) will see the query results in order to answer your questions. This is the same as pasting query results into a chat — the LLM provider sees the data you ask about, but not your full database.
